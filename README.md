 AutoSphere - Premium Automotive Website

AutoSphere is a fictional multi-page automotive dealership / vehicle marketplace built as a front-end portfolio project.

 Highlights

- 29 HTML pages
- Responsive premium dark UI
- Interactive inventory filters and local favorites
- Vehicle detail pages
- Vehicle configurator with dynamic pricing and saved builds
- Three-car comparison tool
- Finance calculator
- Trade-in estimate demo
- Service and contact form interactions
- FAQ accordion and scroll reveal effects
- All visual assets stored locally as original SVG illustrations
- No frameworks, no build step, no external dependencies


 Important

AutoSphere is fictional. Vehicle names, prices, specifications, testimonials, offers and team profiles are portfolio content only.
